# AI Support Desk

AI Support Desk — финальный проект курса [**«AI Developer на Python: LLM в реальных приложениях»**](https://stepik.org/course/272727/promo).

Это учебный AI-бэкенд службы поддержки, созданный на Python и FastAPI. Приложение использует языковую модель через OpenAI-совместимый API сервиса ProxyAPI.

## Возможности

В проекте реализованы:

- чат с историей и независимыми сессиями
- потоковые ответы через SSE
- структурированные ответы и проверка через Pydantic
- версионируемые промпты и evaluation-наборы
- Tool Calling с подтверждением изменяющих операций
- анализ документов, таблиц и изображений
- HTTP API на FastAPI
- автоматические тесты через `pytest`
- ограничение одновременных LLM-запросов
- подсчёт токенов и приблизительной стоимости
- структурированные логи
- метрики Prometheus и дашборд Grafana
- запуск через Docker Compose

## Настройка

Создайте файл `.env` из подготовленного примера:

```bash
cp .env.example .env
```

Откройте `.env` и укажите API-ключ:

```text
LLM_API_KEY=ваш_ключ
```

Остальные параметры уже содержат учебные значения и при необходимости могут быть изменены.

Файл `.env` содержит секретные данные и не должен попадать в репозиторий.

## Локальный запуск

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите FastAPI:

```bash
fastapi dev app/api/main.py
```

После запуска откройте Swagger UI:

```text
http://127.0.0.1:8000/docs
```

Консольный чат запускается отдельно:

```bash
python main.py
```

## Основные эндпоинты

| Метод и адрес | Назначение |
|---|---|
| `GET /health` | проверка состояния приложения |
| `POST /support-requests/analyze` | структурированный анализ обращения |
| `POST /chat/sessions` | создание чат-сессии |
| `GET /chat/sessions/{session_id}` | получение истории сессии |
| `POST /chat/sessions/{session_id}/messages` | отправка сообщения |
| `POST /chat/sessions/{session_id}/messages/stream` | потоковый ответ |
| `POST /chat/sessions/{session_id}/confirm` | подтверждение действия |
| `POST /chat/sessions/{session_id}/cancel` | отмена действия |
| `POST /files/analyze` | загрузка и анализ файла |

Точные модели запросов и ответов доступны в Swagger UI.

## Проверки

Запуск автоматических тестов:

```bash
pytest -q
```

Тесты используют подготовленные ответы и не расходуют баланс ProxyAPI.

Запуск evaluation-набора:

```bash
python -m evals.run_chat_evals
```

Evals обращаются к настоящей модели, требуют API-ключ и расходуют баланс провайдера.

## Запуск через Docker Compose

Перед первым запуском создайте постоянные тома:

```bash
docker volume create monitoring_prometheus_data
docker volume create monitoring_grafana_data
```

Запустите все компоненты:

```bash
docker compose up --build -d
```

После запуска будут доступны:

- Swagger UI — http://127.0.0.1:8000/docs
- Prometheus — http://127.0.0.1:9090
- Grafana — http://127.0.0.1:3000

Посмотреть журналы AI-бэкенда:

```bash
docker compose logs -f api
```

Остановить контейнеры:

```bash
docker compose down
```

## Ограничения

Это учебная версия приложения:

- сессии и заявки хранятся в памяти процесса
- после перезапуска сохранённое состояние исчезает
- отсутствуют регистрация и авторизация
- ограничитель запросов работает только внутри одного процесса
- качество ответов зависит от модели и провайдера
- рассчитанная стоимость является приблизительной
- Docker Compose предназначен для локального запуска

Для production-системы понадобятся база данных, авторизация, HTTPS, централизованное хранение журналов, безопасное управление секретами и инфраструктура развёртывания.
