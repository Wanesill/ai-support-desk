# Правила возврата. Версия 2

## Срок обращения

Покупатель может обратиться по вопросу возврата
в течение 30 календарных дней после получения товара.

## Необходимые сведения

Нужно указать номер заказа, причину возврата и состояние упаковки.
При повреждении товара необходимо приложить фотографию.

## Рассмотрение

Служба поддержки рассматривает обращение в течение 3 рабочих дней.
